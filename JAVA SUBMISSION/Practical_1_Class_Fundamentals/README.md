# Practical 1: Class Fundamentals

## AIM
To understand and implement fundamental concepts of Java classes including:
- Class declaration and object creation
- Constructors (default and parameterized)
- Encapsulation using private members and public methods
- Static members and methods
- Method overriding (toString)

## Programs Included

### 1. Employee.java
Demonstrates:
- Private instance variables
- Multiple constructors
- Getter and setter methods
- Static variable (count) and static method
- toString() method override

### 2. StudentDemo.java
Demonstrates:
- Constructor chaining
- User input handling
- Encapsulation principles
- Display methods

## How to Compile and Run

### For Employee.java:
```powershell
javac Employee.java
java Employee
```

### For StudentDemo.java:
```powershell
javac StudentDemo.java
java StudentDemo
```

## Key Concepts Covered
1. **Constructors**: Default and parameterized constructors
2. **Encapsulation**: Private fields with public getter/setter methods
3. **Static Members**: Class-level variables and methods
4. **this keyword**: Referencing instance members
5. **Constructor Chaining**: Calling one constructor from another
