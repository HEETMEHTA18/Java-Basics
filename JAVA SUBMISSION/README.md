## 🚀 How to Use This Repository

### Prerequisites
- Java Development Kit (JDK) 8 or higher
- Any text editor or IDE (VS Code, IntelliJ IDEA, Eclipse)

### Compiling and Running Programs

Navigate to any practical folder and run:

```powershell
# Compile
javac ProgramName.java

# Run
java ProgramName
```

**Example for Practical 1:**
```powershell
cd "Practical_1_Class_Fundamentals"
javac Employee.java
java Employee
```

## 📋 Practical List Overview

### 1️⃣ Practical 1: Class Fundamentals
Learn the basics of Java classes, objects, constructors, and encapsulation.

### 2️⃣ Practical 2: String Handling

### 3️⃣ Practical 3: Inheritance, Interfaces & Packages
Implement inheritance hierarchies, abstract classes, and interfaces.

### 4️⃣ Practical 4: Exception Handling
Handle runtime errors gracefully using try-catch and custom exceptions.

### 5️⃣ Practical 5: Multithreaded Programming
